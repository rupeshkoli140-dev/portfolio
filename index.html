Laser Security System

A hardware-based laser security system that uses a laser beam and LDR (Light Dependent Resistor) sensor to detect intrusion. When the laser beam is interrupted by an object or person, the LDR detects the change in light intensity and triggers an alarm (buzzer/LED indicator). The system is built using basic electronic components and provides a low-cost, reliable perimeter security solution suitable for homes or small offices.

LPG Gas Leakage Detection & Control System

This project details an LPG gas leakage detection and control system designed to enhance safety by automatically managing gas flow. The system uses an MQ-5 sensor to monitor the air for LPG concentrations. When a leak is detected, the sensor's voltage output rises, and an Arduino Uno processes this signal via its built-in ADC. If the concentration exceeds a safety threshold, the Arduino triggers exhaust fan and activates a relay to close a 12V solenoid valve, effectively shutting off the gas supply.

Metal Detection System

A metal detection system that uses electromagnetic principles to identify metallic objects. The system is built using a combination of active components, such as the NE555 Timer and logic gates (AND, OR, NOT), and passive components like a detection coil and buzzer. In operation, the NE555 Timer creates an oscillating magnetic field via the coil; when metal is present, it alters this field, triggering a comparator to send a digital signal through the logic gates to activate visual and audible alerts.
